# ポエモン（Poemon）コンセプト

> ステータス: コンセプト確定（2026-09-05）
> 元プロジェクト: sangyoufare2026（メイモン）のコードを雛形として流用

## 1. コンセプト

**「3才の男の子/女の子でも遊べる」AI育成ゲーム**

- 基本無料、全ての機能アンロックは**買い切り**（サブスクではない）
- AIを駆使して**一日一回、日記「ポエム」をつける**ポエモン
- ママやパパに読んでもらって、**ママパパも楽しめる**

## 2. 遊び方（コアループ）

1. 子供は**絵文字つきのキーワード**でポエモンをお世話する
   - 例: 🍎「りんごをたべた」・😊「きょうはたのしかった」・🌙「おやすみ」
2. ポエモンはそのキーワードを**覚えていく**
3. 毎日、覚えたキーワードをもとに**AIがポエムを書き綴る**
4. ママ・パパがそのポエムを読んで、子供と一緒に楽しむ

## 3. ターゲットとデバイス

- **ターゲット**: 3才〜（未就学児中心）
- **デバイス**: スマホより**タブレットをメイン**に据える
  - 大きなタップ領域・シンプルなUI・ひらがな中心
- **共有**: URLで簡単に共有できる（ポエムの公開・家族共有）

## 4. 収益モデル

- **基本無料**（お世話・ポエム閲覧は無料）
- **全機能アンロックは買い切り**（1回の支払いで全機能解放）
  - サブスク課金はしない（子供向け・親の心理的障壁を下げる）

## 5. 広報・共有

- **X（旧Twitter）で広報・共有**していく
- ポエムのURL共有で自然な拡散を狙う

## 6. 技術スタック（sangyoufare2026 からの流用）

| レイヤー | 技術 | 流用元 |
|---|---|---|
| ホスティング | Cloudflare Pages | sangyoufare2026 |
| DB | D1（SQLite） | 同上 |
| キャッシュ/保存 | KV / R2 | 同上 |
| 認証 | Firebase Auth（JWKS自前検証） | `_auth.js` |
| 画像生成 | Gemini → Replicate フォールバック | `_image-gen-core.js` |
| ポエム生成 | Gemini（LLM） | 新規設計 |
| 決定論抽選 | SHA-256 ハッシュ | `_slots.js` |
| 経済 | クレジット（デイリー/買い切り） | `_credits.js` |
| フロント | Vanilla JS | 同上 |

## 7. 開発ロードマップ

- **Phase A: MVP土台**（0.5〜1日）
  - 認証 + 画像生成 + ハッシュ抽選 + 経済
- **Phase B: 育成込み**（2〜3営業日・推奨）
  - レベル/XP/スロット（`_level.js` / `_slots.js` / `_monster-gen.js` の generic化）
- **Phase C: たまごっち完成品**（1〜2週間）
  - 時間経過ティック（新規設計） / 養育UI / LLM対話（ポエム生成）

## 8. 雛形化の3つの守り（sangyoufare2026 から取り込む際の原則）

1. **秘匿情報の排除**: `.env` / `wrangler.jsonc` credential / Secrets → placeholder化
2. **アセットの除外**: `assets/`・`fonts/`・`movie/*.mov` は取り込まない（別人由来の可能性）
3. **generic化**: `aimon` 識別子・定数・効果テーブルを中立化
